# afunnyrat

**Solo developer and worldbuilder.** A Minecraft server, a Chrome extension, an animated series, and a site that rates everything — all built at the same desk.

[**fcthq.com**](https://fcthq.com) is the single index of everything below.

## What I build

| Project | What it is |
| --- | --- |
| **[FunnyCraft](https://mc.fcthq.com)** | Post-apocalyptic Minecraft server — six factions, a working economy with trades and stocks, custom physics, and a story told through an animated series. |
| **[Precision Auto Clicker](https://fcthq.com/pac)** | Chrome extension. Real input through Chrome's own pipeline, so games and speed tests accept it. [Chrome Web Store](https://chromewebstore.google.com/detail/auto-clicker-real-clicks/aookaoedlokejonkfnonlaelbffhocpc) |
| **[FCT: Deep Rock Ember](https://fcthq.com/anime/)** | Animated series, 10 episodes. The war the server was built on. |
| **[TIER EVERYTHING](https://tier.fcthq.com)** | Rate anything in the world on an S-to-D board. Every board is pinned to a real place or a real website. |
| **[FCT Store](https://store.fcthq.com)** | Plush and gear. |
